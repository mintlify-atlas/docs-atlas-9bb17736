Lab 1 walks you through building a Retrieval-Augmented Generation pipeline from scratch using a synthetic company HR and benefits handbook as the knowledge base. Your goal is to create a system that answers plain-English questions about the document and **only** about the document — if the answer is not in the PDF, the system must say so rather than guessing. The lab runs fully in Mock mode, so no API key is needed to complete all five tasks.

## Lab Overview

The knowledge base is a bundled PDF (`SAMPLE_PDF`) containing a synthetic HR handbook. The pipeline you build flows from raw PDF pages through chunking, embedding, and vector storage before it can answer a question. The final task wraps everything in an interactive loop.

```text
          PDF  ──▶  PyPDFLoader  ──▶  Splitter  ──▶  Embeddings  ──▶  ChromaDB
                      Task 1          Task 2          Task 3            Task 3
                                                                          │
                                                                    retriever (k=3)
                                                                          │
                                                             ChatPromptTemplate + LLM
                                                                     Task 4
                                                                          │
                                                              def answer() + while loop
                                                                     Task 5
```

<Note>
  Mock mode is fully supported for this lab. In keyless mode the embedding model is a local FastEmbed ONNX model (~90 MB, downloaded once on first run) and the answer LLM is a local context-grounded stand-in. Switch to OpenAI or Claude mode for real `OpenAIEmbeddings` and a full generative answer.
</Note>

## Task 1 — Load the PDF

Use LangChain's `PyPDFLoader` to load `SAMPLE_PDF` and assign the result to `documents`. The loader returns one `Document` object per page.

```python
from langchain_community.document_loaders import PyPDFLoader

loader = PyPDFLoader(SAMPLE_PDF)
documents = loader.load()

print("Number of pages:", len(documents))
print("First page metadata:", documents[0].metadata)
print(documents[0].page_content[:200])
```

## Task 2 — Split the Document into Chunks

Split `documents` into overlapping chunks using `RecursiveCharacterTextSplitter`. The fixed settings are `chunk_size=1000` and `chunk_overlap=200`.

```python
from langchain_text_splitters import RecursiveCharacterTextSplitter

chunk_size = 1000
chunk_overlap = 200
splitter = RecursiveCharacterTextSplitter(
    chunk_size=chunk_size, chunk_overlap=chunk_overlap,
)
chunks = splitter.split_documents(documents)
print("Number of chunks:", len(chunks))
```

## Task 3 — Generate Embeddings and Store in ChromaDB

Embed the chunks using `get_embeddings(MODE)` and build a real vector store with `make_vectorstore()`. Then run a `similarity_search` to confirm retrieval works.

```python
embeddings = get_embeddings(MODE)
vectorstore = make_vectorstore(chunks, embeddings)

query = "How many casual leave days are provided each year?"
results = vectorstore.similarity_search(query, k=3)
for i, doc in enumerate(results):
    print(f"--- match {i + 1} (page {doc.metadata.get('page', '?')}) ---")
    print(doc.page_content[:200])
```

## Task 4 — Build the RAG Question-Answering Pipeline

Create a retriever from the vector store, build a `ChatPromptTemplate` that instructs the model to answer **only** from retrieved context, and invoke it on a real question. The exact refusal sentence must appear in your prompt.

```python
from langchain_core.prompts import ChatPromptTemplate

retriever = vectorstore.as_retriever(search_kwargs={"k": 3})
llm = get_chat_model(MODE)

prompt = ChatPromptTemplate.from_template(
    """Answer the question using ONLY the context below. Do not use outside knowledge.
If the answer is not in the context, reply exactly:
"I could not find the answer in the provided document."

Context:
{context}

Question:
{question}

Answer:"""
)

question = "What is the standard notice period for regular full-time employees?"
docs = retriever.invoke(question)
context = "\n\n".join(d.page_content for d in docs)
resp = llm.invoke(prompt.format_messages(context=context, question=question))

print("Answer:", resp.content)
print("Pages:", sorted({d.metadata.get("page", "?") for d in docs}))
```

<Warning>
  The grader checks for the exact string `"I could not find the answer in the provided document."` inside your prompt. Paraphrasing it will fail the `grounding` criterion.
</Warning>

## Task 5 — Build an Interactive RAG Loop

Wrap Task 4's logic into `def answer(question)` returning `(text, pages)`, then add a `while True` loop that reads from `input()` and breaks on `"exit"`.

```python
def answer(question):
    docs = retriever.invoke(question)
    context = "\n\n".join(d.page_content for d in docs)
    resp = llm.invoke(prompt.format_messages(context=context, question=question))
    pages = sorted({d.metadata.get("page", "?") for d in docs})
    return resp.content.strip(), pages

while True:
    q = input("Question> ").strip()
    if not q:
        continue
    if q.lower() == "exit":
        break
    text, pages = answer(q)
    print("A:", text)
    print("pages:", pages)
```

<Tip>
  Reuse `retriever`, `llm`, and `prompt` from Task 4 — do not rebuild them inside `answer()`. The grader checks that `retriever.invoke` is called inside the function.
</Tip>
