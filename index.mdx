GenAI Lab is an interactive practice platform for developers learning GenAI and Agentic-AI engineering. Each of the five labs gives you a code editor, real Python execution, progressive hints, and a criterion-based grader that inspects both your code structure (via AST analysis) and the actual runtime objects it produces. No simulation — every run is genuine.

## How the platform works

<Steps>
  <Step title="Pick a lab and a mode">
    Open the Streamlit app, select a lab from the sidebar, and choose **OpenAI**, **Claude**, or **Mock** (keyless) mode. Labs 1 and 5 Tasks 1–3 run fully in Mock mode; agent and tool-calling labs require a real LLM.
  </Step>
  <Step title="Write your code">
    Each task gives you a prompt, starter code, and access to sandbox helpers (`get_chat_model`, `get_embeddings`, `make_vectorstore`, `get_tools`, etc.). Fill in the blanks.
  </Step>
  <Step title="Run and observe">
    Press **▶ Run** to execute Tasks 1…N in the real Python interpreter. You see actual stdout, stderr, and tracebacks — nothing is simulated.
  </Step>
  <Step title="Check, iterate, and submit">
    Press **✓ Check** to grade your code against the rubric. Each criterion shows pass/fail, earned points, and a plain-English reason. Fix, re-run, and press **✔ Submit** when satisfied. Export your final score as Excel, CSV, or JSON.
  </Step>
</Steps>

<Note>
  **Developer mode** — tick **🔧 Developer mode** in the sidebar (or add `?dev=1` to the URL) to see every rubric criterion's pass/fail, earned points, reason, and the exact source the grader executed.
</Note>
