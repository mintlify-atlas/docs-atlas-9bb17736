The fastest way to experience GenAI Lab is to run the Streamlit practice platform locally. The lean `requirements.txt` installs in about a minute on Python 3.12, and **Mock mode** lets you complete Lab 1 (RAG) and Lab 5 tasks 1–3 without any API key. The steps below take you from a fresh clone to your first scored task submission.

## Prerequisites

- **Python 3.12** — required. Python 3.13 causes native-wheel build failures for packages like `ormsgpack` and `chroma-hnswlib`. Use `python --version` to confirm.
- **pip** — bundled with Python 3.12.
- A terminal and internet access for the initial install.

<Steps>
  <Step title="Clone the repository">
    Clone the repo and navigate into the platform folder. The Streamlit app and its `requirements.txt` live in `GenAIPracticePlatform8th/`.

    ```bash
    git clone https://github.com/nithyasatheesh/GenAI-Lab-Sep.git
    cd GenAI-Lab-Sep/GenAIPracticePlatform8th
    ```
  </Step>

  <Step title="Create and activate a virtual environment">
    Isolating dependencies in a virtual environment prevents conflicts with other Python projects on your system.

    ```bash
    python -m venv .venv
    ```

    Activate it for your platform:

    <Tabs>
      <Tab title="macOS / Linux">
        ```bash
        source .venv/bin/activate
        ```
      </Tab>
      <Tab title="Windows">
        ```bash
        .venv\Scripts\activate
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step title="Install the lean dependencies">
    The `requirements.txt` in this folder is deliberately lean — no ChromaDB, LangGraph, or MCP. It resolves to pure-Python wheels and installs quickly. This set fully supports Labs 1 and 2 plus the entire graded UI.

    ```bash
    pip install -r requirements.txt
    ```

    The lean set includes:

    ```text
    streamlit
    pyyaml
    openpyxl
    langchain-core
    langchain-community
    langchain-text-splitters
    langchain-openai
    langchain-anthropic
    openai
    anthropic
    pypdf
    ```

    <Note>
      Labs 3–5 (LangGraph Agent, Multi-Agent, MCP) require the full stack. Install `requirements-full.txt` instead when you're ready for those labs:

      ```bash
      pip install -r requirements-full.txt
      ```

      This adds `chromadb`, `langchain-chroma`, `langgraph`, `mcp`, `langchain-mcp-adapters`, and `fastembed` on top of the lean set.
    </Note>
  </Step>

  <Step title="Start the Streamlit app">
    Launch the app from the same `GenAIPracticePlatform8th/` directory. Streamlit opens a local server and prints the URL.

    ```bash
    streamlit run streamlit_app.py
    ```

    The app will be available at `http://localhost:8501` in your browser.
  </Step>

  <Step title="Open Lab 1, select Mock mode, and run Task 1">
    In the browser:

    1. Select **Lab 1 — RAG with ChromaDB** from the sidebar.
    2. Set the LLM mode to **Mock** (no API key needed).
    3. Read the task prompt and review the starter code in the editor.
    4. Click **▶ Run** to execute your code.
    5. Inspect the output panel — you'll see real stdout, the execution steps, and any errors.
    6. Click **Grade** (or complete all five tasks and visit the **★ Score** page) to see your criterion-by-criterion results.

    <Tip>
      Enable **🔧 Developer mode** in the sidebar (or add `?dev=1` to the URL) to see every grading criterion's pass/fail status, point value, and the exact reason it passed or failed.
    </Tip>
  </Step>
</Steps>

## First-Run Note: FastEmbed Model Download

The first time you run Lab 1 in keyless (Mock) mode, GenAI Lab downloads the FastEmbed ONNX embedding model — approximately **90 MB**. This happens once and is cached locally. Subsequent runs start instantly.

If you're on a very restricted network or want to skip the download entirely, switch to **OpenAI mode** with a valid `OPENAI_API_KEY` — this uses `OpenAIEmbeddings` and never downloads a local model.

## Enabling Real LLM Mode

Set one of the following environment variables before launching the app. The sidebar automatically detects the key and switches to the appropriate real mode.

<Tabs>
  <Tab title="OpenAI">
    ```bash
    export OPENAI_API_KEY=sk-...
    streamlit run streamlit_app.py
    ```

    Uses `ChatOpenAI` with `gpt-4o-mini` by default. Override the model with:

    ```bash
    export OPENAI_MODEL=gpt-4o
    ```
  </Tab>
  <Tab title="Claude (Anthropic)">
    ```bash
    export ANTHROPIC_API_KEY=sk-ant-...
    streamlit run streamlit_app.py
    ```

    Uses `ChatAnthropic` with `claude-sonnet-4-5` by default. Override the model with:

    ```bash
    export ANTHROPIC_MODEL=claude-3-5-haiku-20241022
    ```
  </Tab>
  <Tab title="Windows (PowerShell)">
    ```powershell
    $env:OPENAI_API_KEY = "sk-..."
    streamlit run streamlit_app.py
    ```
  </Tab>
</Tabs>

<Warning>
  API keys are read **only** from environment variables or server-side secrets. They are never hard-coded in source and never sent to the browser. Do not paste your key into the code editor inside the app.
</Warning>
